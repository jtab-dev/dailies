# What is `dailies`?

## Overview

A terminal-based screen saver and idle-game inspired by the ‘daily objective’ mechanics of Gacha
Games built on Rust. The user creates a list of their daily objectives (exercise for at least
20 minutes, practice the guitar for an hour, complete this homework assignment, etc.) and get rewarded with
currency to roll for characters that can jump around and facilitate the idle-game. This application
allows one to track their tasks and creates the incentive to be more productive.

## Features

- Vim-styled Controls
- To-do List and Management
- Scheduling and Day-Planning System
- Gacha-inspired Character Banners
- Idle Game Screen Saver
