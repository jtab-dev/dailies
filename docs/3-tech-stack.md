# Tech Stack & Hosting Strategy

## Defined Tech Stack

* `Rust`: Used to handle TUI, software files, and base functionality

  * `Crossterm`: Handles the user controls

  * `Serde`: Keeps to-do list and tasks as json-object files

* `ImageMagick`: To make ASCII/ANSI art and UI elements

## Hosting & Deployment Strategy

I plan to host this application using Git and distribute through the AUR (Arch User Repository) and Homebrew
