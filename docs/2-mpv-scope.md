# MVP Scope & Feature Backlog

## The Ultimate Product Vision

A to-do list application that encourages task completion through Gacha Game design-elements.

## The Launch Goal (v1.0 MVP)

To launch a functional version by **December 20, 2026** focusing strictly on core value.

## Feature Prioritization Matrix

* **Must Have (MVP Lineup):**

  * `Vim-style Controls`: This is how the user interacts with the software

  * `Realtime To-do List Management`: This is the main function of the software

  * `Gacha System`: This is the main incentive to complete items on the checklist

* **Nice to Have (Post-Launch Backlog):**

  * `Calendar/Scheduling`: Not necessary for tasks meant to be done daily, but nice to have so app can have mor encourages  
  * `Idle-game`: Not necessary for a "to-do list" app, but does provide incentive for the Gacha System
